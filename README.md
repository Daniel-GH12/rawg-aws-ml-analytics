# RAWG Games API - Análisis de Éxito de Videojuegos

[![Project Status](https://img.shields.io/badge/status-active-brightgreen.svg)](https://github.com/Daniel-GH12/rawg-aws-ml-analytics)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

API para predecir el éxito de videojuegos y responder preguntas sobre la base de datos RAWG.

## 📌 Descripción del Proyecto

Este proyecto implementa un flujo completo de análisis de datos para videojuegos desde la extracción de datos hasta la predicción de éxito:

1. **Extracción masiva** de datos de la API de RAWG (2016-2026)
2. **Almacenamiento estructurado** en PostgreSQL
3. **Definición de métrica de éxito** basada en engagement
4. **Modelo de predicción** XGBoost entrenado con datos históricos
5. **API REST** con endpoints para predicción y consultas

> **Nota del profesor Daniel**:  
> *"El objetivo no es que hagan un modelo increíble... que sea bueno o que sea malo, da igual. Lo importante es que el flujo completo funcione: datos → modelo → API."*
